## 📌 Project Overview
This repository contains an end-to-end exploratory data analysis of customer shopping trends using **Microsoft Excel**. The project leverages raw transaction data to build dynamic pivot tables and interactive visualizations aimed at understanding sales performance, purchasing patterns, and customer demographics.

---

## 📂 Repository Structure

```text
customer_shopping_excel_analysis/
│
├── Data_Science.xlsx     # Main Excel workbook with raw data, pivot tables & dashboards
└── README.md             # Project documentation
```

---

## 🔑 Key Analysis & Highlights

- **Data Processing & Cleaning:** Data formatting, handling missing fields, and structuring dataset variables.
- **Pivot Table Analysis:**
  - Revenue distribution across different categories and product lines.
  - Demographic breakdowns (Age group, Gender, and Regional distribution).
  - Purchase frequency and payment method preferences.
- **Visual Dashboards:** Excel Pivot Charts and visualizations summarizing key business metrics and shopper trends.

---

## 🛠️ Tools Used

- **Microsoft Excel**: Pivot Tables, Pivot Charts, Formulas, Data Filtering, and Formatting.

## 🚀 How to Run / Explore

1. Clone or download this repository:
   ```bash
   git clone https://github.com/csathishit89/customer_shopping_excel_analysis.git
   ```
2. Open `Data_Science.xlsx` in Microsoft Excel, Excel Online, or Google Sheets.
3. Switch between worksheet tabs to view the raw data, calculations, pivot summaries, and chart dashboards.
